# 产品愿景

本文负责Chico的长期产品方向，不承担功能清单、交付计划或具体实现设计。

## 初始愿景

Chico面向需要持续处理研究证据、组合状态、风险约束和决策记录的专业投资用户。产品将 agent 能力嵌入可审计的投资工作流，使用户能够更快形成判断，同时保留数据来源、时间语义、授权范围和人工责任。

## 目标结果

- 把分散的研究材料、市场数据和组合事实组织成可追溯的工作上下文。
- 让 agent 的分析、建议和行动准备能够被专业用户检查、纠正和复现。
- 通过统一运行时约束控制模型、工具、数据和外部副作用，而不是依赖提示词自律。
- 用可重复评测衡量投资任务质量、风险违规、延迟和成本。

## 非目标

- 不以替代投资负责人、风险负责人或交易授权人为目标。
- 不把自然语言输出视为已经验证的事实、投资结论或交易授权。
- 不在缺少数据来源、有效时点和权限记录时执行外部副作用。

## 需要验证的问题

- 首个付费用户及其最高频、最高成本工作流是什么？
- 工作台首先服务研究、组合管理、风险监控还是交易准备？
- 哪些能力必须在单一会话内完成，哪些需要长期任务和跨会话状态？
- 哪些司法辖区、机构政策和数据许可会约束产品范围？
