# 评测资料

本目录负责 Chico 的 benchmark 场景、数据集说明、评分规则和结果报告。代码的单元测试、e2e 和快照仍放在所属代码包；这里保存产品级任务定义和跨版本对比证据。

## 资料类型

| 类型 | 内容 |
|---|---|
| Benchmark 场景 | 专业用户目标、输入、允许工具、约束和可观察成功条件 |
| 数据集说明 | 来源、许可、版本、时间范围、脱敏和使用限制 |
| 评分规则 | 正确性、风险、审计、延迟和成本的计算方式 |
| 结果报告 | 基线、候选版本、配置、重复次数、统计结果和已知限制 |

## 规则

结果报告必须引用不可变的数据和配置身份，区分确定性 fixture 与真实 API 运行，并同时报告质量、风险、延迟和成本。不得提交受许可限制的原始市场数据、客户数据、账户信息或凭证。

能力级评测计划与 PRD 和规格放在同一个 `capabilities/<name>/` 目录中。跨能力指标在出现共同需求后新增所属文档，不预先建立运行时指标体系。
