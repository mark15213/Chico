# 安全与权限控制

本文定义Chico跨进程、模型、工具、数据和用户界面的权限要求。具体沙箱和服务接口仍由 Harness 安全文档和所属包负责。

## 最小权限

每个 agent、插件、工具和后台任务只获得完成当前工作所需的最小权限。未配置的能力默认不可用；缺少依赖时快速失败，不能静默切换到权限更宽的提供方。

## 权限维度

文件、网络、数据集、账户、模型、工具、子进程、外部系统和人工批准是独立权限维度。权限计算需要包含主体、资源、动作、环境、时间和委托链。

## 不可信输入

市场数据、网页、附件、工具结果和模型输出都可能包含恶意或错误指令。系统不得让内容数据改变插件组合、提升权限、读取凭证或绕过人工确认。

## 凭证

文档、Session 日志、模型上下文和评测产物不得包含明文凭证。工具通过凭证引用或受控运行环境获取秘密，并限制返回值和错误信息中的泄漏。

## 委托

子 agent 和后台任务只能获得父级权限的显式子集，并记录委托来源和有效期。跨 Session 恢复委托时必须重新验证当前主体和资源授权。

## 安全失败

策略冲突、身份不明、授权过期或审计存储不可用时，涉及敏感数据或外部副作用的操作默认拒绝。错误信息必须指出缺少的条件，但不能泄漏秘密或扩大资源可见性。
