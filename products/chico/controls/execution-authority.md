# 外部执行授权

本文定义Chico向交易、消息、文件发布或其他外部系统提交副作用时的最低授权要求。领域角色和行为层级见 [`../foundations/risk-and-authority-model.md`](../foundations/risk-and-authority-model.md)。

## 明确授权

外部执行需要可验证主体、允许的操作、资源范围、金额或数量限制、有效时间和批准来源。模型建议、工具可见性和历史上执行过类似操作都不构成授权。

## 执行前检查

提交前必须展示结构化意图、目标系统、关键参数、使用数据的有效时点、策略检查结果和预期副作用。需要人工批准的操作在批准前不得调用外部执行接口。

## 幂等与核验

每项可重试副作用必须携带稳定幂等身份。超时或连接中断后先查询外部系统确认结果；无法确认时记录未知状态并阻止自动重复提交。

## 授权生命周期

授权在取消、到期、主体退出、作用范围变化或上级权限收缩时失效。恢复的 Session、子 agent 和后台任务必须重新解析当前有效授权，不能复用陈旧进程内判断。

## 最终责任

工作台记录提出、审核、批准、提交和核验各阶段的主体。系统不得把 agent 标记为承担法律或机构上的最终投资责任。
