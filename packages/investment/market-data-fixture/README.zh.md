# @deepseek-ai/dsh-market-data-fixture

[English](README.md) | 中文

确定性行情 Service Provider：固定的标的表和可复现的 K 线序列，让无密钥快照、演示和测试无需交易场所权限即可跑通 [`ctx.marketData`](../market-data/README.md)。它以 id `fixture` 注册。

## 确定性

每个取值都由标的的 symbol 和配置的 `anchorDate` 推导，因此两台机器上的两次运行结果一致。序列是两个正弦项的闭式组合而非伪随机生成器，这意味着任意单个交易日都可以在不遍历序列的情况下算出，并且这里不读取任何时钟——输出随墙上时钟变化的提供方无法支撑可重放的快照。

`anchorDate`（默认 `2026-08-14`）是序列结束的交易日。`quote` 用该交易日与其前一日作比较，`priceHistory` 返回以该日结束、按数量请求的交易日序列，按日期升序。

`available()` 恒为真：fixture 表没有凭据也不联网，因此没有任何可失去的东西。

## 表里有什么

三个标的——`SZSE:300750`、`SSE:600519` 和 `SZSE:300274`——各自带有显示名称、币种和锚定收盘价。其他标的一律以 `MARKET_DATA_UNKNOWN_INSTRUMENT` 拒绝而不是合成，这样本应连到真实提供方的测试会大声失败，而不是悄悄读到编造的价格。

K 线报告 `adjustment: 'none'`，这是准确而非约定俗成：该序列是合成的、不含任何公司行动，因此其价格在构造上就是未复权价。

## Model Experience

### Fixture 行情

#### 模型看到什么

什么都看不到。本包不注册工具、不注入提示词；它向 `ctx.marketData` 贡献一个提供方，而建立在该接缝之上的工具包拥有面向模型的表面。

#### Token 影响

每次请求的直接 token 消耗为零。

#### KV Cache 影响

与实时请求无关：本包从不触及请求前缀，因此无法使提供方的缓存复用失效。

## Known Limitations and Deferred Work

- **交易日跳过周末但不跳过节假日。** 跨越市场休市日的序列会报告一个并未交易的交易日。建模交易场所日历需要真实的日历数据源，那属于真实提供方而不是 fixture。
- **价格看似合理，但并不真实。** 序列没有跳空、没有涨跌停、事件前后也没有成交量异动，因此在测试依赖这些特征的行为时无法替代真实数据。
- **表固定在源码里。** 新增标的是一次代码改动，没有配置路径，因为可配置的 fixture 会让两个部署对 `fixture` 的含义产生分歧。
