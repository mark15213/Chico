# @deepseek-ai/dsh-client-ui-watchlist

[English](README.md) | 中文

Web 对话视图环上的**自选**标签页。浏览器插件注册一个本地化的 `conversation.view` 贡献，id 为 `watchlist`，order 为 20，与对话和轨迹标签页并列；视图环外壳由对话主体拥有，一次只渲染一个标签页。挂载该标签页时通过 [`api-remotes`](../../api/remotes/README.md) 调用 `ctx.remote.watchlist.list()`，由[自选投影](../../investment/watchlist/README.md)提供服务。

每一行是一个关注的标的：`MARKET:SYMBOL` 身份、带交易场所币种的最新价，以及带符号的涨跌幅。报价缺失的行保留其位置并显示**无报价**——记录完好无损，而停牌的标的恰恰是用户需要看到的那一个。

行的上方是一个搜索框。输入即按代码或名称检索上市标的，每条匹配要么带一个关注按钮，要么标明它已在列表中；显示名由交易场所返回，而不是取自这里输入的任何内容。候选列表渲染在输入框**下方**而不是覆盖在行之上，因此可以在不关掉任何东西的情况下把一条匹配与已关注的内容作比较。

点击一行的名称会在同一个标签页内打开该标的：数字、最近六十个交易日的蜡烛图、记录起始时间，以及回到列表的入口。页面**替换**列表而不是在旁边打开，因为详情栏仍归工具检查器所有——关于谁拥有那一栏的[开放问题](../../../products/chico/workbench-design.md)会一直悬置到个股档案的内容值得为它争论为止。

该标签页在记录为空时依然有用：空的自选表会说明如何填充它，而不是渲染一个空白面板。加载、失败与重试都局限在已挂载的组件内，读取失败也从不暴露传输层细节。

## 两个界面，一份数据

本包注册两次：标签页，以及侧边栏会话浏览器上方的固定列表（`sidebar.pinned`）。两者渲染同一批行，因此在标签页里关注一只标的，侧边栏会随之变化。

这批行不是槽位的 `store` 句柄。一个句柄只承载一个作用域，而这两个槽位并不共享同一个——视图环是会话作用域，侧边栏是 root 作用域——而这批行两者都不是：它们是一本账，在每个会话里都相同。因此插件持有一个普通的可观察对象，把同一份订阅交给两个注册。在一次读取进行中再请求刷新会加入那一次，因为两个界面都会在挂载时刷新。

侧边栏那一半依托 `ctx.slots.inject`，因此没有 `ui-sidebar` 的组合只会得到标签页。

固定列表是展示，不是导航：它的行不打开任何东西。侧边栏是 root 作用域，而两个可能接收标的的界面——视图环与详情栏——从那里都够不着。它最多显示八只并注明省略了多少只，因为固定区域占用自身高度，不能挤压会话浏览器。

## 视图环里放了一个数据不按会话划分的标签页

`conversation.view` 槽位是会话作用域的，而自选表是一本账，在每个会话里都相同。该标签页仍然放在这里，因为那正是专业用户在"读对话"与"读持仓"之间切换的位置；组件不从会话快照取任何东西，因此每个会话显示相同的行。

## 涨跌方向被表达了两次

价格方向遵循本产品服务的本地市场惯例——红涨绿跌——并通过主题令牌取色，因此两种主题都能正确解析。符号同样写在文本里，方向也放在 `data-direction` 属性上，因此一行在灰度、色觉障碍以及读取 DOM 的测试下都成立。

数字使用等宽数位，好让一列价格对齐；涨跌幅补齐到固定宽度也是同一个理由。

## Model Experience

无，因为本包在 Host 拥有的投影之上渲染一个浏览器标签页，不注册任何面向模型的内容。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## Known Limitations and Deferred Work

- **每次挂载或显式刷新只读一次**——该标签页不订阅报价变化，也不在重连后重新拉取，因此一屏打开着的自选表的新鲜度取决于上一次读取。
- **价格显示到两位小数**——这是今天所服务的交易场所的报价精度；最小变动价位更细的场所会让小数位数成为一个本组件尚未携带的按场所划分的事实。
- **检索结果是一个扁平列表，没有自己的分组或排序**——匹配按提供方给出的顺序到达，因此一段指向许多上市标的的查询没有任何按场所或按品种收窄的办法。
- **个股页面只有数字和图，没有任何记录**——笔记、洞察、财报和公告都不存在，因此该页面陈述的是市场对这只标的说了什么，而不是用户对它说了什么。
- **页面替换列表而不是与之并列**——读者无法在不返回的情况下把一只标的与自选表其余部分作比较，这是把详情栏留给工具检查器的代价。
