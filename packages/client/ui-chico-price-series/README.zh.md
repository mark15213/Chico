# @deepseek-ai/dsh-client-ui-chico-price-series

[English](README.md) | 中文

Chico toolview 插件：`market_history` 对应的 `tool.call.toolview` 键控注册方。它组合共享的 [ToolRow](../ui-tool/README.md) 外壳，并把蜡烛图作为该行的 `customCard` 提供，因此价格序列走的是与其他所有卡片行相同的、默认折叠的交互。

`priceSeriesModel` 是把快照 `resultView` 上的 `card: 'price-series'` 渲染意图转换成图表所需数据的唯一位置；图形几何和表头摘要都由它一次性推导。

## 回落到通用卡片的情形

图表只在结果时出现，因此运行中的调用只显示摘要行——行情工具在待定阶段保持通用卡片。已结算的调用在下列情况同样走通用路径：结果视图是通用卡片（调用失败）、`card` 标签是本 UI 版本不认识的值（该值经由更新的宿主从线上到达，不能假定它是已编译的变体之一）、序列为空，或序列中每个价格完全相同。最后一种是有意为之：平坦序列没有区间，在任意高度画一条线等于宣称数据并不具备的形状。

未加载本包的组合会保留通用卡片以及工具自身结果文本里的 K 线表格，而这正是 `price-series` 渲染意图对不具备该能力的 UI 所作的承诺。

## 呈现

单位盒从序列最低点向上计数，而 SVG 向下计数，因此组件只在绘制处翻转一次，除此之外不做任何算术——每个值到达时都已推导完成。没有实体高度的交易日（开盘等于收盘）绘制为一条细线而不是零高度矩形，以保持可见。

颜色遵循产品所服务市场的本地约定：上涨为红、下跌为绿，取自主题 token，因此两种主题都能解析。复权方式始终显示在区间旁边，因为不说明价格采用哪种公司行动基准的图表，恰恰会诱发行情接缝存在的目的所要防止的那种比较。

## Model Experience

无，本包在浏览器中渲染一次已完成的工具调用；这里没有任何内容会到达模型请求。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## Known Limitations and Deferred Work

- **没有悬停读数或十字线。** 图表给出序列摘要和区间；要读某一个交易日的具体数值需要看工具的结果文本。逐根交互需要一套该行展开手势目前并不共享的指针模型。
- **成交量被携带但未绘制。** 渲染意图包含每个交易日的成交量，模型层将其丢弃；成交量副图需要在行内占用自己的垂直空间。
- **一张卡片一条序列。** 在同一坐标轴上比较两个标的，需要能携带多条序列的渲染意图，而不是客户端合并。
