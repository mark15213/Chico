# Agent Note：Chico 提供 mock 行情数据

Status: implemented

[English](2026-08-16-chico-serves-mock-market-data.md) | 中文

## Problem

Chico 的组合从 Tushare 读取价格，而这个依赖恰恰在界面正被构建的场景下让产品不可用。在 token 有效、网络可达的一次会话里观察到三个失败：

- 模型并发发出了 `market_quote` 与 `market_history`。三个 HTTP 请求同时打到 Tushare——`quote` 除了 K 线还要读一次标的名录——其中一个返回 `TypeError: fetch failed`。provider 没有任何重试，于是 quote 失败，而它旁边的 history 成功了。
- 自选列表为每只关注的标的读一次报价，因此同一类失败让左栏在 "Reading the watchlist…" 上转了超过九十秒，之后名称档案面板显示 "No quote"。
- 这些都不是在描述工作台，而是在描述网络。

组合自己的 README 主张的恰恰相反——工作台绝不能把虚构收盘价当作场所自己的价格呈现，因此 `dsh-market-data-fixture` 被刻意排除在外。对于读者会据价格行动的部署，这个论点是对的；对于本组合当前仅有的那些部署——它们存在的目的就是构建和演示界面——这个论点是错的。

## Decision

**Chico 组合提供合成价格，并且明说这一点。** patch 层的数据源行现在是 `@deepseek-ai/dsh-market-data-mock`，它从编译进包内的数据集作答，不需要凭证也不访问网络。组合 README、包 README 以及 provider 的模块文档都以「每一个价格都是合成的」开篇。

**新建 provider 包而不是复用现有 fixture。** `dsh-market-data-fixture` 在三个标的上计算闭式正弦序列；它的确定性支撑着无密钥快照，而那些快照的期望输出正是对着这些值记录的。把它改写成提供另一套数据集，会因为与快照覆盖内容无关的原因重写那些快照。

**数据集编译进包内，而不是从仓库读取。** `src/dataset.ts` 由 `scripts/build-dataset.mjs` 从 `mock-data/data/` 生成并提交。已发布的包无法访问一个只存在于本 checkout 的目录，而在运行时读 JSON 会让 provider 的答案依赖于自身目录树之外的路径。采用列存而非 bar 对象数组：同样的 500 个交易日，源码文本约为三分之一。

**十个标的，由接缝能够寻址的范围决定。** 六只个股加四条基准指数。源数据集里的两只场外基金被跳过，因为 `Market` 是闭合联合，没有为不在任何场所交易的基金准备的成员——接缝没有它们的地址，而为了一个 fixture 的方便去改接缝是本末倒置。

**`disabled: true` 把 provider 移出选择范围。** 误挂载它的组合会以 `MARKET_DATA_PROVIDER_UNAVAILABLE` 失败，而不是把虚构收盘价当作场所自己的价格呈现出来。

**Tushare 保留在工作区中。** 对于想要实时价格的部署，它是一个可用的 provider；换回那一行就是全部改动，因为 `market-data` 不锁定 `provider`，选择会解析到唯一可用的那个。

## Alternatives considered

**给 Tushare provider 加重试和缓存。** 被否决，因为这不是该先解决的问题。重试会让观察到的失败变得更罕见，却不会让界面变得可复现；正在构建的工作台仍然无法离线演示、无法确定性截图、无法回放。该 provider 缺失重试对任何换回这一行的部署仍是真实缺口，记录在它自己的 README 里，而不是在这里修掉。

**挂载现有的 fixture provider。** 被否决：三个标的的正弦序列画出的图表没有任何真实形状，而该包的确定性对现有快照是承重的。

**通过可配置路径在运行时读取 `mock-data/data/`。** 被否决，因为这会让一个包的答案依赖于自身目录树之外的目录，而且该路径在已发布的安装里根本不存在。

**保留 Tushare，接受界面降级。** 依据证据被否决：一个转了九十秒的自选列表和一个显示 "No quote" 的档案面板，不是降级的界面，而是不存在的界面。

## Consequences

Chico 现在无需任何行情凭证、无需网络可达即可启动运行。自选列表立即填充，每张图表都能绘制，并且在每台机器、每一次运行中出现的都是同样的价格——这正是让界面可演示、让它的截图可对比的前提。

组合展示的每一个价格都是虚构的。**当前界面没有任何地方在显示处标明一个价格是合成的**：`Quote` 与 `PriceBar` 不携带来源字段，因此由该 provider 绘制的图表与由交易场所数据绘制的在视觉上完全相同。组合 README 与 provider README 都写明了这一点；如果这个组合有朝一日要展示给可能据数字行动的人，界面层的标记——报价上的角标，或接缝上的来源字段——是显而易见的后续工作。

数据集止于固定的锚定日（2026-08-14）且永不前进，因此把它与墙上时钟比较的界面报告的是一段随 checkout 一起变旧的序列。

bundle 的组合测试随决策改变了形态：原先断言「不发布任何合成 provider」，现在断言「发布 mock 数据源，且没有实时数据源与之并存」；而真实组合的启动测试完全不打 `fetch` stub——任何触达网络的调用都会让测试失败，这正是要断言的性质。
