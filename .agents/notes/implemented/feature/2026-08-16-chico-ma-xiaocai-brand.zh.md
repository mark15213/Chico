# Agent Note: Chico 蚂小财产品品牌

Status: implemented

[English](2026-08-16-chico-ma-xiaocai-brand.md) | 中文

## 问题

Chico 浏览器构建继承了共享的 DeepSeek Harness 标题、鲸鱼字标、favicon、安装元数据和欢迎声明。因此，即使 Chico profile 已经组合出独立的投资工作台，用户看到的仍是框架品牌，而不是产品身份。

## 决策

Chico 交付 workspace 以 `蚂小财 Harness` 呈现产品。浏览器文档标题、会话标题后缀、安装 manifest、欢迎声明、展开态侧边栏字标、收起态侧边栏图标、空白会话首页和 favicon 都使用这一身份。视觉图标是由本地 SVG 几何图形绘制的蚂蚁，在浅色和深色主题下跟随既有前景色。

提供方身份保持不变。DeepSeek 模型名称、官方提供方设置流程、凭据键、package scope、wire 标识符和仓库术语仍然描述它们实际对应的后端和框架；产品展示不会改写这些技术名称。

## 曾考虑的替代方案

**替换仓库中每一处 DeepSeek。** 不采用：很多匹配项代表官方模型提供方、npm scope、API 凭据、wire 值或上游框架。改写它们会破坏配置或错误描述后端，而不是为 Chico 更换品牌。

**保留鲸鱼，只更改可见文字。** 不采用：图标和 favicon 是最持续、最显著的品牌线索，浏览器标签页和收起态侧边栏中尤其如此，因为这两处不显示产品文字。

**使用远程图片资源。** 不采用：应用必须在离线时仍然拥有完整品牌，也不应在用户采取任何操作之前发起外部请求。

## 后果

编译后的 Chico Web 产物在浏览器外框、首次引导和导航中使用统一的产品身份。蚂蚁 SVG 在本地打包，不新增网络依赖。这个 workspace 会有意改变 Chico profile 所使用的共享 Web 展示；作为提供方或框架约定标识的 DeepSeek 技术名称仍然保留。
